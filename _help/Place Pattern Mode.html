Place pattern mode is instigated from the Patterns popout from the main menu or, if a pattern is already selected, by pressing ⌥P.

When in pattern place mode, the selected pattern will appear on the grid as a highlighted overlay.
Move the pattern to the desired position using keys ←, →,  ↑  and  ↓ . Use key ⌥R to alter the rotation.

Once the desired position and rotation are found, press ↩ to place the pattern on the grid.

Press Esc to abandon the pattern placement and exit placement mode.
