The Meta Rules popout is available from the main menu.

Select an existing meta rule from the dropdown, or enter a new name to create a new meta rule.

When a meta rule is selected, choose the Edit radio button to view or edit the meta rule definition. Changes to the definition are reflected in the number of Matched rules shown at the bottom of the popout.
If there is an error in the meta rule definition - it is displayed below the edit area.

Select the Matching Rules radio button to display the rules matched by the current meta rule. Clicking a rule in the list sets it as the current rule.

Use the Delete button to remove the selected meta rule.

For details of the meta rule language and syntax, see the Meta Rules Reference.
