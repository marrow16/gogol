File finder is the built-in file (and path) selector for GoGoL - replacing native OS file finders and file open dialogs.
It specifically allows previewing .rle files (including meta data). It also allows limited previewing of .png, .jpg, .jpeg and .gif files.

The file finder can be reached by pressing the ... button in Load Patterns, Grid Recipes or Import Grid.

Usage

Path shows the current path:
• 
Click on any of the path items to navigate up the folder path.
• 
Press key ← to navigate up to parent folder.
The left pane shows the list of files and folders in the current path:
• 
Clicking on any file or folder selects it.
• 
Use keys  ↑   ↓  PgUp PgDn Home and End to navigate.
• 
When on a folder, click again or press → to navigate into that folder.
• 
Press any character key to navigate to the next file/folder whose name starts with that character.
The right pane shows the details of the currently selected file or folder:
• 
If the currently selected file is a .rle, .png, .jpg, .jpeg or .gif - a preview is displayed.
The bottom pane shows controls:
• 
Use the Only show selectable files checkbox to limit files shown to only those that can be selected.
• 
Click Open button to select the current file/folder and return to the calling popout.
This button will be disabled if the current file type is not allowed or selecting a folder when folder selection is not permissible.
• 
Click on Cancel button or press Esc to exit file finder
Note: Clicking on the window close will not close the file finder - it will close the entire application!
