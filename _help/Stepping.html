Use the Stepping popout from the main menu to adjust the stepping settings.

The Step delay (ms) setting determines the delay between each step (in milliseconds) and can be set to a value between 0 and 2000.

The Step ahead size setting determines the number of steps that are performed with a step ahead - and can be set to a value between 1 and 9999.
Step ahead is instigated by pressing key ⌥⇥ or clicking on the statusbar.

Use the Snapshot on step ahead checkbox to determine whether a snapshot of the grid is automatically taken on every step ahead.


Note: The step delay is decoupled from the GUI frame rate - and setting a step delay of 0 (zero) will run the simulation as "close to the metal" as possible with visual updates at ~30Fps.
