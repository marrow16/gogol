The Collected Rules popout is available from the main menu.

Collected Rules are a list of curated rules that are of interest - the list shows the currently collected rules. Clicking on an item in the list sets the current rule.

If the current rule is already in the list it will be highlighted - and you can use the Remove Current button to remove it from the list. Conversely, if the current rule is not in the list, use the Add Current button to add it to the list.

Use the Clear button to clear the entire current list.

The Commonality shows the meta rule representing the common properties of the collected rules (see meta rules) - along with a count of current collected rules against a count of rules matched by the commonality.
Commonality is updated every time a rule is added or removed from the list.

You can edit the Commonality - and, after editing, hitting ↩ will update the list with rules that match that meta rule.
