The Patterns popout is available from the main menu.

This popout shows all patterns currently loaded - see Load Patterns for adding more patterns.

Select a pattern from the dropdown - you can also type a name into that dropdown to search for pattern(s) by name.

Having selected a pattern, choose the Preview option to view a preview of the pattern or choose Metadata option to see the pattern metadata (from the .rle file - and including the filename).

Press the Place button to place the pattern onto the grid (see Place pattern mode).
Check the Interlaced option to place the pattern interlaced - where dead cells in the pattern do not overwrite alive cells in the grid.

Choose the Search/filter option to create filters for the patterns shown in the dropdown:
• 
All filter fields are optional - leaving them empty has no effect.
• 
Enter a Rule (e.g. "B3/S23") to filter patterns to that rule - or check the Filter current rule option to filter patterns to the currently active rule.
• 
Use Width and Height entries to filter the patterns to ranges of specific sizes.
• 
Use Name, Filename, Origin and Comment entries to search/filter pattern metadata.
Having entered your filter criteria, press the Apply Filter button to apply - the number of found patterns will be displayed.
Use the Clear Filter button to unapply the filtering.
