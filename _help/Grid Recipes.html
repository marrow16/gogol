The Grid Recipes popout is available from the main menu.

Select an existing grid recipe from the dropdown, or enter the path to a recipe .json file. Alternatively, use the ... button to open the file finder.

Selecting a recipe file registers it for use by GoGoL. The recipe is not loaded, parsed or validated at this point - the file is only read when the recipe is run.
Because recipes are loaded on demand, the recipe file can be edited and re-run without restarting GoGoL.

Press the Run button or press ⌥G to execute the selected recipe. If the recipe cannot be loaded or contains an error, the error will be displayed.

Use Save as RLE button to execute the recipe and save the resulting grid as an RLE file.

For details of the Grid Recipe JSON format and available operations, see the Grid Recipes Reference.
