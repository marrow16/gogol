The Shortcuts popout is available from the main menu.

Shortcuts are named macros that can execute an action or series of actions in GoGoL.

Select an existing shortcut from the dropdown, or enter a new name to create a new shortcut.

If the shortcut name matches a keyboard key, it can be invoked by pressing ⌥ plus that key. For example, a shortcut named A can be invoked by pressing ⌥A - likewise, a shortcut named F1 can be invoked with ⌥F1
Note: Shortcut keys can override can override GoGoL assigned keys.

Having selected or created a shortcut, use the Actions area to edit the actions associated - each action on a new line. See Shortcuts Actions Reference.
