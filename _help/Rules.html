Use the rules popup to select the currently active rule.

The rules popup is available by clicking the rule area in the statusbar or by pressing ⌥L.

The list at the top shows the named rules - click on an item in that list selects that rule. You can also navigate around that list using keys ▲ ▼ or by pressing any letter key.

The bottom of the popup shows details about the currently active rule - which can also be interacted with to change the rule:

Name
Shows the name of the current rule.
If the current rule is already named this cannot be changed - however, if the current rule is custom, the name can be changed and a Save button allows the rule name to be saved for future use.
Rule
Shows the actual rule string - born (B) and survives (S)
Edit the rule string to change the rule. (see also below for changing the rule by keys)
Perm.
Shows the permutation for the rule (0 to 262143) - an 18-bit number where born (B) is the high order 9-bits and survives (S) is the low order 9-bits.
Change the value to change the rule, or use  ↑   ↓  to increment/decrement. Use PgUp PgDn to increment/decrement the high order 9-bits.
Integer
Is an alternative rule numbering system defined by conwaylife.com/wiki.
(GoGoL prefers to use the permutation numbering system because it keeps behaviours together by numeric proximity)
Add Collected / Remove Collected
Use these buttons to add or removed the current rule to/from collected rules.
Which button displayed indicates whether the current rule is currently collected.

Changing rule with keys

The current rule can be altered at any point (without opening the rule popup) by using the following shortcut keys:
Ctrl+0 - Ctrl+8 toggles the corresponding digit in the born (B).
⌥0 - ⌥8 toggles the corresponding digit in the survives (S).
