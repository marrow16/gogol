Use the Colors popout from the main menu to adjust the colors of cells on the grid.

Each color setting, Alive cells, Dead cells & Cell border, is represented by a R(red), G(green) & B(blue) component - enter a value between 0 and 255.
Within each color component input, use keys ▲ and ▼ to increment/decrement the value.

Use the Show Borders checkbox to determine whether the grid displays borders.
Cell borders can also be toggled by pressing key ⌥B.
