Edit mode allows you to edit the current grid. Start edit mode by pressing ⌥E or selecting Edit mode from main menu.

To exit edit mode, press Esc or ⌥E again. Edit mode is also terminated by opening main menu; clicking on statusbar rule; or clicking any of the simulation start/step buttons. The and buttons can be used during edit mode.

During edit mode, the left panel of statusbar will show the current edit position - which is also indicated by a blinking cursor in the grid.
