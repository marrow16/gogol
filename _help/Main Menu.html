The main menu can be shown by clicking the button on the status bar or by pressing key ⌥M

The menu contains the following options:

Help or press key F1
Show this help screen.
About
Shows application version and information.
Patterns
Shows the Patterns popout.
Captured Patterns
Shows the Captured Patterns popout.
Load Patterns
Shows the Load Patterns popout.
Instrumentation
Shows the Instrumentation popout.
Shortcuts
Shows the Shortcuts popout.
Meta Rules
Shows the Meta Rules popout.
Collected Rules
Shows the Collected Rules popout.
Grid Recipes
Shows the Grid Recipes popout.
Size/Wrapping/Boundaries
Shows the Size/Wrapping/Boundaries popout.
Stepping
Shows the Stepping popout.
Colors
Shows the Colors popout.
Snapshot or press key ⌥S
Takes a snapshot of the current grid.
Undo to snapshot or press key ⌥Z
Restores the grid to the last snapshot.
Export Grid or press key ⌥X
Exports the current grid as a .rle file in the documents/GoGoL folder.
Import Grid
Shows the Import Grid popout.
Edit mode or press key ⌥E
Places the grid into edit mode. See Edit Mode
Randomize or press key ⌥R
Clears the current grid and adds random alive cells.
Random Noise or press key ⌥N
Adds random alive cells to the current grid.
Clear or press key ⌥C
Clears all cells in the current grid.
