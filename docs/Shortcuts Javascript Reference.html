Shortcuts can execute javascript using the following action:
javascript:filename
• 
where filename is either an absolute path - or is taken as a relative path from [user]/Documents/GoGoL/
• 
the script is compiled as ECMAScript 5.1 - any compilation errors are logged to [user]/Documents/GoGoL/errors.log
• 
the script is not cached - it is compiled from the file each time the shortcut is run. Therefore, between shortcut runs, the script can be modified with external editors.

Notes:
• 
By default, no exceptions are raised by functions - any errors or invalid args are logged to [user]/Documents/GoGoL/errors.log
Note: To override this default behavior and make errors raise exceptions - use exceptions = true;
• 
Most arg values are coerced - for example: sleep("10"); is equivalent to sleep(10);
• 
Shortcuts executing javascript can still be interrupted by press key Esc - but the interruption only occurs at the next function call.
