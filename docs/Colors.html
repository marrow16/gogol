Use the Colors popout from the main menu to adjust the colors of cells on the grid.

Each color setting Alive cells, Dead cells & Cell border is represented as an edit with the #rrggbb color string. Use  ↑  and  ↓  keys to increment/decrement any part of the color string. Click the color box (or press ↩ key) to show the color picker. Having changed the color, use key ⌘Z to revert.

Use the Show Borders checkbox to determine whether the grid displays borders.
Cell borders can also be toggled by pressing key ⌥B.
