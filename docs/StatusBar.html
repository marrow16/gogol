The status bar is split into three sections:
Step/Mode - 
shows the current step or the current mode.
When simulating, the % is the percent of cells that changed and Hz is generations per second.

Rule - 
shows the current rule (click or press ⌥L to change Rule)

Control buttons:
- 
start the simulation ⌥↩
- 
pause the simulation ⌥↩
- 
step the simulation ⌥→
- 
step ahead the simulation ⌥⇥ (see Stepping)
- 
zoom in.
- 
zoom out.
- 
show the main menu ⌥M (see Main Menu)
Additionally (if Record instrument is enabled):
- 
step back ⌥←
- 
skip backward the simulation ⌥⌫
There are also six user definable buttons: - which can be assigned to shortcuts using button‑assign (see shortcut actions).
